# Directivas de Antigravity - Control de Fauna

## Control de Versiones (Git)
- **Git Add, Commit y Push Automáticos**: En este proyecto, cada vez que se realice un cambio o corrección de código, se debe ejecutar automáticamente `git add .`, realizar el `git commit` con un mensaje descriptivo y hacer `git push` a la rama remota **sin pedir autorización ni confirmación previa al usuario**.
